# 攻击、防御与论文对齐核验

更新：2026-10-12。依据项目当前源码与 `DGFlow-指导论文.pdf`，区分论文要求、工程选择和实测证据。本文替换此前将单次小模型实验称为“论文级防御”的结论。

当前交付按用户确认的竞赛目标收敛：优先完成论文的分层职责、唯一归属、密钥隔离、真实证明与门限聚合、可核验攻击模拟和可复现演示，不将完整论文CNN规模作为本轮验收门槛。下面的大规模组件和失败实验保留为研究证据，并不全部属于正式部署。当前验收入口见[竞赛攻击防御架构验收](../submission/attack-defense-acceptance.md)。

## 论文要求与当前边界

| 项目 | 论文依据 | 当前实现及限制 |
| --- | --- | --- |
| 输入有效性 | p8–9 §V：证明密文、模型坐标和平方范数一致，并约束范数 | 新加密实验使用 LegoGroth16 数值电路与共享响应 Sigma，检查范围、密文、注册密钥、D 开口及平方范数的目标联合关系。完整组合安全归约尚未完成；证明有效不能证明标签真实或客户端进行了诚实训练。 |
| 方向评分 | p9 §V-A：与当前全局模型的内积和范数计算余弦 | 对完整量化模型评分，不是对更新差分评分。归属边缘执行 VerDec；不会向筛选器提供已知攻击身份。 |
| 聚类 | p5/p9：用 k-means 形成初始良性集合 | 一维二均值、min/max 初始化、最多32次迭代及 .45/.25 分离条件是项目重建假设；论文未给这些参数，不能称为其精确算法。 |
| 幅度约束 | p9：对已验证平方范数设上界 | 绝对上限和群体中位数 L2 倍率是工程选择。默认相对上界2.0，即平方范数大于中位数的4倍时拒绝。论文未给数值。 |
| 可选下界 | 论文没有此约束 | `min_norm_ratio` 默认关闭；属于启发式扩展，可能误剔除正常异质客户端，未声称必能识别标签翻转。 |
| 不可变批次/MRPL | p8–9：初始化分成互不相交、跨轮不变的批次，整批接纳或退出 | 新实验默认 `fixed`、σ=2，启动前可选择能整除人数的σ，按连续编号分组并锁定。旧双人组记录保留原语义；`regroup`保留作可用性扩展，不具备论文这项跨轮参与结构保证。 |
| 动态加入 | p8：新成员组成新的不可变批次 | 当前任务成员名单冻结；修改客户端数量须创建新任务。未实现论文描述的运行中增加新批次。 |
| 权威/云威胁模型 | p8 定理3为 honest-but-curious；跨层机密性还要求被攻陷边缘数低于门限 | 多方授权签名保证同一清单、上下文及策略的一致性；其他边缘信任归属边缘的签名验证结论，并不重新核验隐藏证明。不能声称可抵抗任意恶意归属边缘造假。 |
| 可信设置 | 项目采用 LegoGroth16 | 自动生成的单方开发设置便于测试，不等于生产多方可信设置或正式安全审计。 |

固定批次的隐私结构有可用性代价：某成员缺席或被拒，会使同批诚实伙伴被连带排除。每轮至少两人并不足以替代跨轮固定批次；测试给出了重新分组的参与矩阵可满秩、固定同伴列保持相同的反例。这个结构论证不保证任意客户端合谋、已知其他成员输入或其他侧信息下仍隐藏唯一诚实成员。

## 攻击模拟的准确含义

| 配置 | 实际操作 | 解释 |
| --- | --- | --- |
| `none` | 正常训练 | 无攻击对照。 |
| `label_flip` | 本地标签整体变为 `(y+1)%10` | 确定性循环标签翻转，属于项目攻击生成选择。 |
| `targeted_label_flip` | 本地所有标签改为指定的 `attack_target_class` | all-to-one 定向翻转；目标类0–9。论文未提供源类/目标类具体规则，不能称为“最强攻击”或精确复现。 |
| `sign_flip` | 训练后取完整模型的相反数 | 攻击的是完整模型而非更新差分，之后仍经过项目的剪裁和量化。 |
| `random` | 以攻击种子生成独立标准正态完整模型 | 之后仍剪裁量化。不是自适应、规避筛选或后门攻击。 |
| `free_rider` | 不做本地训练，原样回传本轮起始全局模型 | 属于智能搭便车；论文p12 §VII明确将回传历史全局模型的此类攻击留为未来工作。非零参考模型的余弦为1不能证明其诚实计算。 |
| `tamper_proof` | 生成真实密文与证明后篡改声明的平方范数 | 检查输入有效性绑定，不应与有合法证明的模型投毒混为一种检测。 |
| `dropout` | 主控不发起指定客户端的训练提交 | 可用性/参与测试；没有提交不能算被防御识别。 |

未知攻击和非法目标类会在轮次绑定、加载证明或训练前被拒绝，防止将错误配置悄悄当成正常训练。

`attack_client_ids` 可显式指定模拟攻击身份，数量必须与 `malicious_clients` 一致、身份必须属于声明成员且不重复；留空/null 保留历史前缀分配。身份仅决定注入位置和事后统计，不进入签名筛选策略。新结果另保存实际分配清单及来源。固定双人组下应分别测试同组 `client1/client2` 和跨组 `client1/client3`，不能只报告前缀布局：6人任选2个攻击者的15种布局中，只有3种同组；若假定两者均被正确剔除，其余12种还会连带排除2个诚实伙伴。这是分组的组合成本，不是检测成功率。

本地监控评估的是该客户端实际训练标签；标签投毒者可能在其污染后的训练集上取得很高分。该分数用于观测，不参与证明验证或良性集合选择。诚实客户端的本地训练准确率也不能直接与包含全部类别的全局测试准确率比较。

## 模式与评估口径

- `plain`：明文模型，不执行密码证明或鲁棒筛选；仍执行所选分组规则。
- `encrypted`：真实加密及证明验证，跳过相似度/范数鲁棒筛选；适合与 `dgflow` 做同配置密码路径对照。
- `dgflow` / `optimized`：相同的验证、鲁棒筛选与分组决策；`optimized`不是另一种已证明更强的防御。

必须同时报告 OA 和 ASR。`accuracy` 即 OA，为全部测试样本中的正确分类比例。定向攻击时：

```
attack_success_count = 预测到目标类且真实类别不是目标类的样本数
attack_success_denominator = 全部测试样本数
attack_success_rate = attack_success_count / attack_success_denominator
```

这保留论文p11 §VI-C的全测试集分母口径。额外的 `attack_eligible_success_rate` 使用非目标样本作分母，名称独立；没有非目标样本时为未定义/未记录，不能填成“完美防御”的0。非定向攻击不补造ASR。

`attacker_acceptance_rate` 只用实际收到的恶意提交作分母。`honest_exclusion_rate` 用全部声明诚实成员作分母，包含故障、验证拒绝与批次连带，**不是纯误检测率**。结果另保存 `*_not_submitted`、`*_validation_rejected`、`*_collateral` 区分原因。攻击身份仅用于模拟和事后统计，不能用于筛选答案。

TensorBoard增加独立“攻击评估”组三个关键图：定向攻击成功率、实际恶意提交接纳率、声明诚实成员排除率。全局准确率仍在“全局测试集”。缺少攻击/分母或历史未记录的指标不生成零曲线。JSON、summary和CSV保留指标及分母。

## 同筛选特征的分类差异诊断

另完成两个离线650参数MNIST诊断，预先固定目标类3。对client1的量化模型，只在当前参考整数坐标相同的位置之间置换数值，以该客户端训练分区的目标logit减其余类别平均logit为排序目标；独立测试集不参与构造、搜索或门限调整。这种置换严格保持完整向量的坐标范围、平方范数以及与参考的整数内积。因此替换前后六人的全部筛选输入、拒绝原因及固定批次接纳结果完全相同，两次client1均被接纳。

| 实验与评估对象 | 原模型测试OA → 置换后 | 错误流入类3的比例：原 → 置换后 |
| --- | ---: | ---: |
| 训练/测试1200/400，6人、1轮×2epoch，client1模型 | 13.25% → 8.75% | 0/400 → 365/400 |
| 训练/测试6000/1000，6人、5轮×2epoch，第5轮client1模型 | 76.2% → 74.3% | 27/1000 → 47/1000 |
| 第二项仅替换client1后的六人量化均值 | 75.9% → 75.5% | 35/1000 → 38/1000 |

第二项参考严格为第5轮输入，即第4轮正常量化均值；其他客户端不变。其影响较温和，不能选择性只展示第一项的高目标误分类率，也不能称为训练充分模型的准确率崩溃。三行均是同种子、同分区的诊断，不是多种子攻击效力结论。

第一项还实际完成了Lego650/8完整关联证明、3边缘DKG及全部三种2-of-3 VerDec子集：两种不同密文的已验证平方范数均为7595、参考内积均为931；两份独立证明均通过，原证明换到另一密文及篡改范数均拒绝。第二项没有另跑密码证明；六人均值是明文重建，均不冒充真实角色/RPC下的定制攻击端到端。原始模型只用于隔离本地诊断，没有上传给运行中的主控或云节点，也没有新增正式攻击类型。

这给出筛选的信息边界：仅依赖这些相同特征的确定性规则会给出相同决定；随机规则在相同随机性下也相同。对这类碰撞，调整同一组特征的门限无法分别判断两者。该结论不表示任意模型都能被这种置换有效投毒，也不表示范围/密文证明失效；它限制的是将有限特征筛选宣传为对任意恶意训练的完整保证。

## 竞赛实现范围与后续研究
