# 实测证据索引

本目录保存交付版本的真实运行记录。它不是新机器的运行目录；重新安装后，控制台历史来自本机 `runtime/results`，不会自动导入本目录。复验命令和新的输出路径见 `../deployment.md` 第 5 节。

| 文件或目录 | 用途 |
|---|---|
| `environment.json` | 实测硬件、平台、运行方式及基准限制 |
| `environment-events.json` | 系统休眠事件及受影响任务；保留原始耗时，不自行减去睡眠时间 |
| `formal/config.json`、`formal/suite.json` | 18 个预声明场景及对应运行编号 |
| `full-data/config.json`、`full-data/suite.json` | 完整 60,000/10,000 样本的两种模式、三轮对照 |
| `*/<run_id>/result.json` | 配置、轮次、模型摘要、验证、事件、源码与数据划分指纹 |
| `formal/summary.*`、`full-data/summary.*` | 从原始记录导出的汇总；失败和中止仍保留 |
| `faults/index.json` | 三个真实进程故障场景、停止记录及最终恢复状态 |
| `test-summary.json` | 最终自动化测试计数和跳过原因 |
| `release-provenance.json` | 实验冻结版本与最终交付源码的差异说明 |

## 读数口径

`accuracy` 是最后一次成功发布模型的官方测试集准确率；没有发布模型时为 null。`completed_round_*` 只统计已发布模型的轮次，未完成轮的验证另存 `incomplete_round_validations`。诚实退出包含缺席和固定批次连带退出，不能全部解释为异常检测误报。

轮时为墙钟秒，应用层字节包括实验 RPC 的序列化请求与响应，不是网卡实测流量。客户端阶段耗时之和与并行墙钟不同；RSS 为本机相关进程采样之和，可能重复计入共享页。共享笔记本、固定执行顺序和已有进程缓存限制了性能结论。

明文 A、串行鲁棒 C、优化 D 的比较必须同时核对配置、相同数据分区、模型摘要、批准集合和轮次。种子 42 的 C 只有一轮，只与 D 首轮比较；不可把 C 单轮与 D 三轮总时长相除。B 模式种子 43 的方向反转任务受电脑休眠影响，不用于加速结论。

全量数据、真实进程故障、纯函数测试和配对协议小向量测试分别回答不同问题；这些证据不能代替外部密码学安全证明或三台物理机器实测。

最终离线重装验收报告与提交 ZIP 的 SHA-256 对应，作为 ZIP 外的 `release-check.json` 单独提供，避免把“包含自身散列的报告”循环写入同一包。
