# 2026-10-13 监控页面重做验收

本次将监控从整屏 TensorBoard 调整为运行总览、节点与资源、深入分析三层工作区。总览优先呈现实验身份、任务状态、完成轮次、全局测试效果和采集情况；深入分析保留原生 TensorBoard。2026-10-10 的验收记录描述此前版本，保留作为历史资料，不能据此证明本次界面通过验收。

## 数据与显示边界

- 只读取所选实验的结果、监控快照和持久化记录；实验切换后不将旧详情或迟到响应显示为新实验。
- 缺失读数与实际零值分开：未记录显示说明或“—”，曲线断开，不填造评估点、资源值、节点身份或当前阶段。
- 全局测试与客户端本地训练标明不同评估集；初始评估、全局轮次与本地 epoch 保留各自坐标口径。
- 阶段耗时是对应已记录轮次的事后计时，不宣称实时阶段；父子计时及并行节点累计不直接相加。
- 任务状态与采集状态分开；采集异常不推断进程退出或业务失败。历史记录显示截至结束时的数据，不冒充当前资源状态。
- 节点进程 CPU/RSS 与整机资源分开；主机按机器去重，GPU 不按节点分摊或重复相加。
- 首次进入深入分析才挂载 TensorBoard；同步不重建已加载 iframe，分析异常局限在分析面板。

## 验收范围

前端检查覆盖：总览真实组件渲染、缺失与零值、无实验和等待采样、历史未记录、节点/主机资源分离、实验切换迟到响应、采集失败保留快照、TensorBoard 延迟挂载与后台状态保持。

浏览器检查应核对桌面与窄屏布局、页内导航与键盘操作、抽屉详情、轮次进入验证页、实际可见图表点，以及页面异常和接口失败的影响范围。浏览器构造样本只用于验证映射与交互，不能作为真实训练效果、性能或密码学结论。
