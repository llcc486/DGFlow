# 训练曲线与 TensorBoard

## 使用

启动新版控制服务后，进入“监控”，在“当前实验”中选中一次实验。

- 准确率与损失按全局轮次绘制。第 0 轮来自初始模型评估，之后每个点来自已完成的一轮聚合后评估；正在执行的一轮不会提前生成结果。
- 硬件图按实际采样时间绘制，通常每秒采一次，页面沿用约 2 秒一次的实验轮询。驱动较慢时以真实时间间隔为准。结束后的图来自保存的实验记录。
- 展开 TensorBoard 面板即可使用其原生缩放、平滑和实验选择功能，也可在新标签页打开。面板展开后约每 10 秒补录一次当前实验已有记录；原生 TensorBoard 的页面刷新周期也会影响显示延迟。日志汇集了已经导出的实验，请在 TensorBoard 内勾选需要的 run。
- 查看旧实验时，可以从已有记录补录 TensorBoard。旧记录没有的硬件指标仍显示“未采集”，不能通过补录还原当时未采集的数据。

## 指标口径

| 曲线 | 含义与单位 |
| --- | --- |
| 准确率 | 全局模型在该实验所配置的 MNIST / CIFAR-10 测试子集上的准确率；页面为百分比，TensorBoard `evaluation/accuracy` 为 0–1 |
| 损失 | 同一测试子集的交叉熵，TensorBoard `evaluation/cross_entropy`；不是各客户端训练损失的平均值 |
| CPU | 主控所在机器的整机 CPU 使用率；实验进程 CPU 另列，按逻辑核数归一化到整机容量的 0–100% |
| GPU | 现有 NVML 采样器所选本机 GPU 的计算利用率；不表示三台机器的 GPU 总和 |
| 显存 | 同一 GPU 已使用/总显存，页面用 GiB；“显存占用”不同于显存控制器忙碌率 |
| 系统内存 | 本机系统内存占用量、总量和占比；来自 psutil |
| 实验进程内存 | 主控和已核对身份的本机角色及其子进程 RSS 之和；共享页可能重复计算，不能与系统内存直接相加 |
| 磁盘 | runtime 所在文件系统的已用容量、总容量及占比，包含该盘其他文件；不是 runtime 文件夹自身大小 |

GiB = 1024³ 字节。硬件曲线横轴为实验耗时（秒）；TensorBoard 硬件 scalar 的 step 是采样序号，可切换 Wall/Relative 时间。缺失值不写入 TensorBoard，监控图中留空；0 仅表示真实采到零。首个实验进程 CPU 读数没有相邻时间差，通常为空。两次采样间已退出的短命工作进程可能未被完整计入。

当前资源图覆盖**主控所在机器**。三机部署的另外两台机器尚无远端资源上报；远端节点健康状态依然来自已有健康检查，不能把本机资源曲线当作整个集群的资源用量。

## 安装与保存

TensorBoard 2.21.x 已加入基础依赖。已有环境在项目根目录执行：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
Set-Location web
npm.cmd ci
npm.cmd run build
Set-Location ..
```

再按部署手册重启控制服务。新环境使用原有部署脚本即可。离线环境需在联网准备机用新版依赖重新生成离线包；旧 wheelhouse 可能缺少 TensorBoard、protobuf、grpcio 等新增依赖，不能只复制本次源码后继续沿用旧离线包。

事件文件保存在 `runtime/tensorboard/<run_id>/events.out.tfevents.*`，与 `runtime/results/<run_id>/result.json` 分开。备份对照实验时可保存这两个目录，勿混入 `runtime/keys`。TensorBoard 使用控制服务的同源 `/tensorboard/` 路径，无需再启动 6006 端口或开放防火墙。前端开发服务也配置了这个路径的代理。

未安装或无法加载 TensorBoard 时，原有训练和监控曲线仍可使用；面板会显示原因。磁盘满或事件写入失败时，检查空间和目录权限后再次打开/刷新面板补录已有记录。TensorBoard 日志仅导出标量，不写入私钥、客户端原始样本或单个客户端模型梯度。

## 验证方式

通过 TensorBoard 自带 event reader 核对初始轮次、逐轮准确率/损失及资源指标；重复导出和服务重启后不得重复记录同一个 tag/step。控制 API 测试同时检查实际嵌入页面、scalar HTTP 端点、未知实验 404 和同源访问限制。前端测试覆盖单位转换、空值断线、数据排序及面板生命周期。
